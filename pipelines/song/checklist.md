# Production checklist

Tick items as you finish them (`- [x]`). The next session resumes from the first unticked one.

## Genre
- [ ] 5+ sources read on the genre
- [ ] `music/genre.json` written · `strudel.mjs genre` passes · `mfx step done genre`

## Blueprint
- [ ] Dramatic reading of the topic
- [ ] Genre signature (hook + beat), motif, tempo/meter/key, chart, roles on channels, sections, length
- [ ] `strudel.mjs plan` passes · `music/BLUEPRINT.md` submitted

## Score and MIDI
- [ ] Score written from the approved blueprint (notes only)
- [ ] `strudel.mjs check` at 0 problems · MIDI captured (`music/notes.json`, `out/music/midi/`) · `mfx step done score`

## Instruments
- [ ] `music/instruments.json`: a sound for every channel, with why
- [ ] `strudel.mjs instruments` passes · `strudel.mjs audition` passes · `mfx step done instruments`

## Mix and master
- [ ] Studio finish: `strudel.mjs master` passes, balance notes acted on · or owner's finish: `strudel.mjs own-master` passes
- [ ] `mfx step done mix`

## Final
- [ ] Master, music sheet, MIDI (and stems if asked) submitted
- [ ] Every note answered in the next version (if any)
