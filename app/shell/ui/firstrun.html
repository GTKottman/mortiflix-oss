Before your first video

Mortiflix Studio uses a few programs it can't ship itself. Install what's missing, then press Check again. You can also continue now and add them later in Settings.

Claude Code
The AI that writes and builds your videos, with your own Claude login. Official install command:
irm https://claude.ai/install.ps1 | iex
Git for Windows
Claude Code runs its commands in Git Bash on Windows, and the studio's renders use it too. Install command:
winget install --id Git.Git -e --source winget
